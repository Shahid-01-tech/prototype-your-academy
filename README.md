# Teacher Educational Platform Prototype

A student-friendly educational platform prototype for a teacher/educator.

## Demo structure

- `/` — Student home page
- `/student/live.html` — Live classes
- `/student/lectures.html` — Recorded lectures
- `/student/courses.html` — Courses
- `/student/course-details.html` — Course details
- `/student/my-learning.html` — My Learning
- `/student/video-player.html` — Video player
- `/student/profile.html` — Student profile
- `/admin/` — Teacher/Admin dashboard

## Technology

- HTML
- CSS
- JavaScript

## Run locally

Open the project in VS Code and use Live Server, or open `index.html` directly in a browser.

## Deploy to Vercel

Import this GitHub repository into Vercel. Keep the project root as `./`. No build command is required for this static prototype.

After deployment, the main student experience is available at `/`, and the teacher dashboard is available at `/admin/`.

## Note

This is a UI/UX prototype. It uses demo content and interactions. Real authentication, database, payments, video hosting, live classes, and production security are not included yet.
